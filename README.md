# DriveTheory B PWA

Устанавливаемое офлайн-веб-приложение для iPhone. Подходит для бесплатного GitHub Pages.

## Публикация через GitHub

1. Создать публичный репозиторий, например `serdar-drive`.
2. Загрузить содержимое этой папки в корень ветки `main`.
3. GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Открыть выданную ссылку в Safari на iPhone.
5. Safari → Поделиться → На экран Домой.

## Локальная проверка

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`. Service Worker — офлайн-кэш — не работает при открытии `index.html` напрямую как файла.

## Содержимое

- 53 карточки;
- 5 партий по 30 вопросов;
- калькулятор формул;
- штрафные баллы и правило двух ошибок по 5;
- локальное сохранение прогресса;
- офлайн после первого открытия.

Учебные вопросы являются авторскими переформулировками правил, а не копией закрытого каталога TÜV/DEKRA.

## Smart Coach (2026)

- «Сегодня» показывает ежедневный план 30.10–28.11.2026: одна тема в школьной программе и одна в платной (каждая — полный тест из 30 вопросов).
- «План» записывает выполнение, число правильных ответов и штрафные баллы.
- «Ошибки» принимает скриншоты iPhone. Фотографии сохраняются в IndexedDB только на устройстве.
- OCR на русском и английском (Tesseract.js на устройстве) пытается извлечь вопрос, номер и тему. Требует интернет для первой загрузки моделей. Правильный ответ и зелёные галочки нужно проверять и при необходимости вводить вручную.
- Повторения: первоначально через 3 дня, затем через 4, 7, 14 и 30 дней. Самооценка «Знал / Не знал».
- «Ещё 5 вопросов» использует существующий авторский банк приложения и подбирает вопросы по слабым темам.
- Экспорт/импорт JSON включает фото и прогресс. Фотографии не отправляются на GitHub и в другие сервисы.
- Два примера по скриншотам пользователя: занос задней оси и знак CNG.
- Приложение не заменяет официальный каталог или школьную программу, результаты внутри DriveTheory B — тренировочные.
