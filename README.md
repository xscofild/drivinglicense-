# Serdar Drive PWA

Устанавливаемое офлайн-веб-приложение для iPhone. Подходит для бесплатного GitHub Pages.

## Публикация через GitHub

1. Создать публичный репозиторий, например `serdar-drive`.
2. Загрузить содержимое этой папки в корень ветки `main`.
3. GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Открыть выданную ссылку в Safari на iPhone.
5. Safari → Поделиться → На экран Домой.

## Локальная проверка

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`. Service Worker — офлайн-кэш — не работает при открытии `index.html` напрямую как файла.

## Содержимое

- 53 карточки;
- 5 партий по 30 вопросов;
- калькулятор формул;
- штрафные баллы и правило двух ошибок по 5;
- локальное сохранение прогресса;
- офлайн после первого открытия.

Учебные вопросы являются авторскими переформулировками правил, а не копией закрытого каталога TÜV/DEKRA.
