# DriveTheory B — только Telegram

## Состояние

- **Подготовлено:** код полноценного Telegram-бота и личная Google-таблица.
- **Пока не активировано:** приём Telegram-сообщений, кнопки, сохранение результатов и фото. Для этого необходимо один раз развернуть Google Apps Script.
- Старый Telegram-бот из GitHub Actions **по-прежнему отправляет только утренние сообщения**. Отключи его после проверки новой версии, чтобы не получать дубликаты.
- Токены, ID пользователя и скриншоты **не добавляй в публичный репозиторий**.

## Установка (удобнее сделать с компьютера)

1. Открой личную [Google-таблицу](https://docs.google.com/spreadsheets/d/12ymu4hUvVTWbc0akJ9UPyDOansg31K7nc6qqeA6qLWI/edit). У неё уже есть шесть вкладок: **Plan**, **Results**, **Mistakes**, **Reviews**, **Settings**, **Dashboard**.
2. Выбери **Extensions → Apps Script**. Удали код-заглушку в `Code.gs` и вставь содержимое [Code.gs](./Code.gs). Сохрани.
3. В Apps Script нажми **Project Settings (⚙️) → Script Properties → Add script property**. Добавь:
   - `BOT_TOKEN` = токен от **@BotFather**.
   - `CHAT_ID` = твой числовой Telegram ID.
   Эти значения уже сохранены в GitHub Actions Secrets, но GitHub **не показывает их после сохранения**. Секреты нужно внести отдельно сюда.
4. В редакторе выбери функцию **`setupBackend`** и нажми **Run**. Разреши скрипту доступ к собственной таблице, папке с фото и Telegram HTTP API.
5. **Deploy → New deployment → Select type: Web app**. Выбери **Execute as: Me**, **Who has access: Anyone**. Нажми **Deploy** и скопируй URL, заканчивающийся на `/exec`.
6. Вернись в **Project Settings → Script Properties**, добавь `WEB_APP_URL` = URL из шага 5. В редакторе выбери **`activateWebhook`** и нажми **Run**.
7. В личном чате с [@XscofildDriveTheoryBot](https://t.me/XscofildDriveTheoryBot) отправь `/today`, `/progress`, затем попробуй скриншот ошибки. Если бот отвечает и сохраняет данные в Sheet — всё работает.

**Внимание:** не отправляй значения токена и WEBHOOK_KEY в ChatGPT или GitHub. Web app с доступом Anyone защищает операции секретом в webhook URL и проверяет твой Telegram chat ID. Саму Google-таблицу и папку с фото не делай публичными.

## Как пользоваться

- В 08:00±15 минут по Chemnitz бот отправляет 60 вопросов (30 в школьном приложении + 30 в Special Topics), фокус дня, кнопки.
- После теста нажми **«Результат школы»** или **«Результат Special Topics»** и введи `27 5` — верных из 30 и штрафные баллы. Если баллы не показаны — `27`.
- Просто отправь боту скриншот неправильного ответа; выбери тему. Бот сохранит фото в закрытом Google Drive и назначит повторение через 3 дня, затем через 4, 7, 14, 30 дней при успешных повторах; при неуспехе — на следующий день.
- `/progress` — количество выполненных дней, ошибки, слабые темы, пробные экзамены.
- `/review` — показать скриншот назначенной ошибки и кнопки «Знаю»/«Не знаю».
- В 20:00±15 минут — напоминание только если результат одного из приложений ещё не отмечен.

**Честные ограничения:** бот не получает баллы из сторонних экзаменационных приложений автоматически; вводишь их вручную. Он не распознаёт правильные ответы на скриншотах — для точного анализа можешь писать подпись. Предыдущие скриншоты в DriveTheory B на iPhone не перенесены автоматически, старое приложение пока не удаляй.

Если при отправке `/today` ответа нет, выполни функцию **`checkWebhook`** в Apps Script и проверь Execution log. Если видишь `last_error_message`, он поможет найти причину. Google Apps Script вебхуки могут сталкиваться с редиректами, поэтому проверять надо именно реальной командой, а не только статусом установки.

## Пакетная загрузка скриншотов и подсказка темы (обновление 22.11.2026)

В `Code.gs` добавлены следующие функции:

- Отправляй **5–10 фотографий** в одном Telegram-альбоме или последовательно.
- Каждой фотографии бот присваивает **Ошибка №1, №2...** и отвечает **её же фото с кнопкой** «📚 Выбрать тему». Никаких общих списков без указания фотографии.
- В фоне Google Drive OCR пытается прочитать **номер вопроса** в изображении (например, `1.2.34-110` или `2.5.01-119`). Для них будет предложена соответствующая категория. Ты нажимаешь «✅ Подтвердить» или «📚 Другая тема».
- Категории: восемь точных названий тем школьного приложения. Код вопроса берётся из текста изображения; распознавание может ошибаться. Тему необходимо подтвердить.
- Если OCR не сработал, фото остаётся сохранено и можно выбрать тему вручную. Изображения не публикуются, OCR выполняется средствами твоего Google Drive.
- Повторение начинается после подтверждения темы; ошибка остаётся в закрытом Google Sheets и фото в Google Drive.

**Чтобы включить обновление:** замени код в Apps Script на актуальный [Code.gs](./Code.gs), затем **Deploy → Manage deployments → Edit → New version → Deploy**. `BOT_TOKEN`, `CHAT_ID`, `WEB_APP_URL` и `setupBackend` повторно вводить или запускать не надо. Потом отправь один тестовый скриншот и проверь, приходит ли карточка с кнопками. Если OCR недоступен, кнопка ручного выбора всё равно работает.
